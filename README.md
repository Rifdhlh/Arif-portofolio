# Muhammad Arif Fadhilah — Portfolio

Personal portfolio of an Information Systems student at BINUS University, Jakarta, Indonesia.

## Website

https://muhammad-arif-fadhilah-portfolio.arifadhilah542.chatgpt.site

## Structure

- `dist/index.html`: profile, skills, and contact details
- `dist/database-projects.html`: Long-Life Shoe Factory
- `dist/system-analysis-projects.html`: Information System StSport
- `dist/web-development-projects.html`: Vincraft
- `dist/assets/`: images and tool logos

The website uses static HTML, CSS, and JavaScript. Open `dist/index.html` in a browser to preview it locally. No build step is required.

GitHub stores a copy of the website source. Changes here do not automatically update the Sites deployment.
