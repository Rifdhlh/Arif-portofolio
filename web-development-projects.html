Project Overview

Vincraft brings Minecraft community content into a website where visitors can browse posts, search by title, and filter by category. Registered users can participate through posts and community interactions, while administrators manage content and user activity.

My Contribution

I was responsible for writing the HTML and CSS that structure and style the website. I also contributed to selected simple JavaScript logic to support interface interactions.

Application Features

Content and community workflows.

Features represented in the submitted source code.

01 / Discovery

Browse and filter

A homepage with recent posts, plus title search and category filters on the browsing page.

02 / Publishing

Create and edit posts

Forms for a post's title, category, description, thumbnail, and optional video link, alongside a personal post list.

03 / Interaction

Likes, comments, and reports

Post detail pages combine community feedback with a reporting flow for content that needs attention.

04 / Administration

Manage community content

Separate management pages for users, categories, posts, and submitted reports.

Project Technologies

The project combines HTML, CSS, and JavaScript for the interface with PHP and MySQL for server-side processing and data storage, developed locally using XAMPP. The database schema includes users, categories, posts, comments, likes, resource files, and reports.
